# A two-line morning poem

This repository is an entry for make.fun's bounty `u-gudril-cool-two-lines-of-morning-light-ade94fc5`: entrants write one two-line micro poem about light and morning, and an AI judge compares poems in pairs. It contains a single program, `main.py`, which writes one fixed short text to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), creating that folder when needed, printing the character count to stderr, and asserting that the text is between 1 and 280 characters long.

The entry text, written without a trailing newline:

```text
The cat has not moved since six.
The square of light has, and takes her with it.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
